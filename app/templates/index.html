SEM ADMINISTRADOR LOCAL

Rodar remotamente pelo painel

Configure o WinRM HTTPS uma única vez dentro do RDP. Depois, selecione WinRM HTTPS (5986), informe a conta administrativa do servidor e use normalmente o botão Analisar servidor.

Baixar configurador WinRM HTTPS
O configurador exige um certificado de computador válido para o DNS do servidor. Execute-o como administrador apenas no servidor.

Alternativa sem abrir canal remoto

Se a política não permitir WinRM, colete dentro da sessão RDP e importe o JSON. O servidor remoto não precisa de Python.

  1. Copie o arquivo Collect-SqlServerAdvisor.ps1 para o servidor pela sessão RDP.
  2. Abra o PowerShell como administrador e execute .\Collect-SqlServerAdvisor.ps1.
  3. Traga o JSON criado na Área de Trabalho e selecione-o abaixo.
Baixar coletor PowerShell
Coleta somente leitura. Senhas não são gravadas no arquivo de diagnóstico.
